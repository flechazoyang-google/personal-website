「作品一号」COC 部落战数据管理工具

头版 · 战报管理

部落冲突的管理者大概都懂这种痛：几十号人的进攻记录散落各处，谁没打、谁打了三星，全靠手动翻聊天记录。这个应用的起点，就是把这件琐事变成"粘贴 JSON，一切自动"。

自动匹配花名册的模糊推荐、三星率 / 参战率 / 有效进攻率统计、未进攻成员一键公示；单场导出与全量备份，WebDAV 云端同步（支持坚果云），换手机也不丢战报。目前版本 v3.8，仍在随部落战节奏持续迭代。

KOTLIN 2.0JETPACK COMPOSEROOM + KSP MVVMWEBDAV（零依赖）

「作品二号」Toolbox —— 十七件工具，一个箱子

专题 · 工具箱

计算器、汇率换算、IP 属地、倒数日与纪念日、加密密码箱、BMI、九宫格切图、番茄钟、拼豆图纸、Base64、时间戳、二维码、亲戚称呼计算、经期记录、去水印、加水印、收藏 —— 十七件日常工具全部离线可用，密码与数据只存本机。

最新 v1.4.4：经期记录新增排卵期 / 易孕期 / 安全期三段式推算；倒数日支持农历与 14 个内置节日；拼豆图纸可保存高清 PNG。Gitee / GitHub 双源自动更新。

KOTLINCOMPOSE + MATERIAL3HILT RETROFIT + OKHTTPROOM
